## 课程定位

CS 228 是经典的 PGM 课程，覆盖 Bayesian/Markov network、HMM、精确与近似推断、参数/结构学习。它提供的“用图结构编码不确定性”的思维方式，对 NLP、计算生物、因果推断和机器人都有长期价值。

## 主要内容

- **表示**：贝叶斯网络、马尔可夫网络、因子图
- **精确推断**：变量消元、信念传播、junction tree
- **近似推断**：变分推断、MCMC、重要性采样
- **参数学习**：MLE、EM、隐变量模型
- **结构学习**：评分搜索、约束方法
- **时序模型**：HMM、动态贝叶斯网络
- **应用**：语音、生物、医疗诊断、视觉、机器人规划

> Probabilistic graphical modeling languages for representing complex domains, algorithms for reasoning using these representations, and learning these representations from data.
