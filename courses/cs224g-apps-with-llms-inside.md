## 课程定位

CS 224G 是一门项目课，把 LLM 当成新的“CPU”，探索围绕它构建应用的方式。课程以两周一个 sprint 的节奏推进，配工业界 guest lecture，适合想快速做出可演示产品的人。

## 主要内容

- **LLM 能力与局限**：幻觉、上下文、成本
- **Prompting**：结构化提示、few-shot、角色设定
- **工具与检索**：function calling、RAG、外部 API
- **应用架构**：前端、后端、流式输出、状态管理
- **快速迭代**：sprint、用户反馈、指标
- **项目**：做一个 LLM-native App

## 考核与工作量

两周一个 sprint 的作业 + 最终项目 + 客座讲座。具体以当季官网为准。

## 适合谁

想快速做 LLM 产品/创业的人；产品经理、设计师、全栈工程师。

## 学习建议

和 CS 329Z 互补：224G 更偏产品节奏，329Z 更偏系统与 eval。先想清楚用户问题，再选模型。
