## 课程定位

CS 229 是 Stanford 最经典、影响最广的机器学习课程之一，理论深度明显高于 CS 230。它不只教“怎么用模型”，更关心模型背后的假设、损失函数、优化过程和泛化行为，是后续做研究或读博的地基。

## 主要内容

- **监督学习**：线性/逻辑回归、广义线性模型、SVM、核方法、树模型与集成
- **学习理论**：偏差-方差、正则化、特征选择、泛化与模型选择
- **无监督学习**：k-means、GMM、EM、PCA、ICA、密度估计
- **深度学习基础**：神经网络、反向传播、训练技巧
- **强化学习**：MDP、值迭代、策略搜索、自适应控制
- **课程项目**：通常是一个开放式的 ML 研究/应用项目

## 考核与工作量

通常为 4–5 次 problem sets + 期中 + final project；每周约 10–15 小时。具体比例以当季官网为准。

## 适合谁

想真正理解 ML 数学原理、之后做研究或读博的人；已经会用 sklearn 但想补推导和理论的工程师；准备面试但不想只背题的人。

## 学习建议

problem set 的推导一定要自己写一遍，尤其是 GLM、SVM 对偶和 EM。配合 CS 229M 或 STATS 315A 可以补齐理论侧。
