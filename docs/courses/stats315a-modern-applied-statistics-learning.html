3 学分 2027 冬 Letter or Credit/No Credit ★★★★☆
统计学习生成模型评估

课程定位

STATS 315A 是统计系研究生级别的 ML 课程，覆盖预测方法（线性模型、树/森林、深度网络）、模型评估（交叉验证、校准、conformal prediction）、优化（凸性、随机方法）和生成模型（语言模型、扩散、VAE）。它兼顾统计严谨性和现代方法。

主要内容

  1. 预测方法：线性、树/森林、深度网络
  2. 模型评估：CV、校准、conformal prediction
  3. 优化：凸优化、SGD、自适应方法
  4. 生成模型：语言模型、diffusion、VAE
  5. 高维与正则：lasso、稀疏性
  6. 项目/论文讨论

先修

概率统计、线性代数、ML 基础（STATS 202/CS 229 级）。

考核与工作量

作业 + 项目/考试。具体以当季官网为准。

适合谁

统计/ML 研究生；想做严谨的预测建模和不确定性量化的人。

学习建议

先修 STATS 202 或 CS 229。conformal prediction 部分很值得深入。

官方课程描述（英文原文）

This course covers statistical techniques underlying modern machine learning. Topics include prediction methods (linear models, trees and forests, deep neural networks), model evaluation (cross-validation, calibration, conformal prediction), optimization (convexity, stochastic methods, adaptive metrics), and generative models (language models, diffusion models, variational autoencoders).
