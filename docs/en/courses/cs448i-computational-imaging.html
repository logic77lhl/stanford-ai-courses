Course positioning

CS 448I (EE 367) is taught by Gordon Wetzstein and is a core course in computational photography/imaging. It combines classical image processing, convex optimization, and modern AI, covering denoising, deconvolution, single-pixel imaging, ToF, wave optics, and end-to-end joint optimization of optics and algorithms.

What it covers

  1. Image processing basics: convolution, filtering, denoising
  2. Inverse problems: deconvolution, regularization, proximal gradient
  3. CNNs for imaging: image restoration, learned priors
  4. Single-pixel imaging: coded apertures, compressed sensing
  5. Wave optics: diffraction, holography, phase retrieval
  6. ToF imaging: depth measurement, multipath
  7. End-to-end optimization: joint optics + algorithm design
  8. Project

Prerequisites

Signal/image processing/optimization basics; Python programming.

Assessment & workload

Assignments plus a term project, emphasizing implementation. Check the current syllabus for details.

Who it's for

Computational photography, imaging systems, AR/VR, and microscopy/medical imaging.

Study advice

Brush up on linear algebra and signals & systems first. Pair with EE 367.

Official course description

Digital photography and basic image processing, convolutional neural networks for image processing, denoising, deconvolution, single pixel imaging, inverse problems in imaging, proximal gradient methods, introduction to wave optics, time-of-flight imaging, end-to-end optimization of optics and imaging processing. Emphasis is on applied image processing and solving inverse problems using classic algorithms, formal optimization, and modern artificial intelligence techniques. Students learn to apply material by implementing and investigating image processing algorithms in Python. Term project.
