Core-course prerequisite text

From the course pages
CS 139Human-Centered AI

No strong technical prerequisites; interest in AI products/policy/ethics.

CS 217Hardware Accelerators for Machine Learning (EE 244)

Digital circuits/computer architecture; VLSI or FPGA experience helps.

CS 221Artificial Intelligence: Principles and Techniques

CS 103 (or 103B/X), CS 106B (or 106X), CS 109, and CS 161. The course explicitly says it will not reteach these foundations.

CS 224NNatural Language Processing with Deep Learning (LINGUIST 284, SYMSYS 195N)

Calculus and linear algebra; one of CS 124, CS 221, or CS 229.

CS 224VAgentic AI

One of LINGUIST 180/280, CS 124, CS 224N, CS 224S, or CS 224U.

CS 224WMachine Learning with Graphs

CS 109; one introductory machine learning course.

CS 228Probabilistic Graphical Models: Principles and Techniques

Basic probability; algorithm design and analysis.

CS 229Machine Learning (STATS 229)

Python/NumPy programming (CS 106A/B level); probability (CS 109/MATH 151/STATS 116); multivariable calculus and linear algebra (MATH 51/CS 205).

CS 229MMachine Learning Theory (STATS 214)

MATH 51; STATS 117; CS 229 or STATS 315A.

CS 230Deep Learning

Python programming; linear algebra (matrix/vector operations). CS 229 may be taken concurrently.

CS 231AComputer Vision: From 3D Perception to 3D Reconstruction and Beyond

Linear algebra; basic probability and statistics; programming.

CS 231NDeep Learning for Computer Vision

Fluency in Python/NumPy; calculus and linear algebra (MATH 19/51); basic probability and statistics (CS 109 level).

CS 234Reinforcement Learning

Fluent Python; CS 229 or equivalent ML background; linear algebra and probability.

CS 236Deep Generative Models

At least one of CS 221/228/229/230; probability and calculus; Python programming.

CS 277Foundation Models for Healthcare (BMDS 271, RAD 271)

CS 229/231N/224N-level ML background.

CS 279Computational Biology: Structure and Organization of Biomolecules and Cells (BIOE 279, BIOPHYS 279, BMDS 245, CME 279)

CS 106A; introductory biology/biochemistry.

CS 329HMachine Learning from Human Preferences

Graduate-level ML (CS 229 level); probability and optimization.

CS 329SMachine Learning Systems Design

At least one of CS 229/230/231N/224N; familiarity with one framework (PyTorch/TF/JAX).

CS 329ZEngineering AI Agents

Programming ability; LLM basics (prompting, API use); ML background is a plus.

CS 336Language Modeling from Scratch

Strong programming; deep learning background (CS 224N/CS 231N/CS 230 level); application required, GPU resources recommended.

CS 349DAI Inference Infrastructure

Systems/architecture/ML basics; distributed-systems experience helps.

CS 349EEfficient ML Inference at Scale (EE 339)

Computer architecture, operating systems, ML basics; strong programming.

EE 292RAI and Data for Science (CS 292, PSYCH 292R, STATS 282)

No hard prerequisites; interest in AI + science is enough.

MS&E 203Building and Evaluating AI Products

Upper-level undergraduates/master's students; programming ability; capacity about 48 students (12 teams × 4).

MS&E 319Efficient Generative Models

ML/LLM basics; algorithmic and systems awareness.

STATS 202Statistical Learning and Data Science

Probability/statistics and linear algebra; programming (R/Python).

CS 224RDeep Reinforcement Learning

See the official description (related courses do not have a separate prerequisite write-up).
