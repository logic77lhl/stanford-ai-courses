六条学习路径

按目标而不是按课程编号选课。每条路径给出核心序列和可搭配课程；先修关系与避坑说明见 learning-paths.md。

LLM / Agent 工程

从 NLP 地基到 agent 工程，再到从零训练语言模型。重点是 eval，而不是只搭 demo。
